# Steam Info Relay

Chrome MV3 확장. `store.steampowered.com/app/*`에서 아래 세 확장이 주입한 DOM을 가로채어
게임 정보 탭(`#glanceMidCtn`, 태그 열 위)에 Steam 기본 행 형식으로 다시 표시하고, 원본 블록은 숨긴다. 링크는 파란색.

- **한글 여부:** KOSTEAM 배너 → `한글 패치(이름) | 한글 패치(이름)`. 이름은 `X님` / `제작자 : X` / `패치 - X` 휴리스틱, 실패 시 사이트명. 퀘이사존 큐레이터 링크는 큐레이터 평가문을 조회해 실제 패치 링크로 바꾼다. `공식 한국어`/`공식(추가정보 존재)`는 SteamDB 평가 녹색의 `공식 한글화`, 패치 링크가 있으면 ` | `로 이어 붙인다. 그 밖에 링크 없는 유형은 유형 라벨만.
- **플레이타임:** Steam HLTB의 `#hltb-glance` → `메인 / 메인+서브 / 완전 정복` 3줄, 값은 `25.5시간` 형식(분도 소수 시간), 탭 간격 정렬.
- **가격:** `현재 ₩ 11,000(-50%)` / `최저 ₩ 5,500(-75%)` 두 줄. 현재가가 곧 최저가면 한 줄 `현재 ₩ 11,000(-50%)(최저)`. 할인율 괄호는 할인이 있을 때만(0%는 생략; 최저가는 SteamDB가 안 주면 정가 대비 계산), 최저 값은 SteamDB 앱 페이지 링크. 무료 게임은 생략.
- **최근 업데이트:** SteamDB 행의 날짜를 `2025년 3월 14일` 형식으로 제자리 변환.

**전제:** 세 확장(Steam HLTB, SteamDB, KOSTEAM)이 설치·활성화되어 있어야 정보가 표시된다.
소스를 읽지 못하면 해당 행만 생략되며, 원본 블록은 여전히 숨겨진다.

설치: `chrome://extensions` → 개발자 모드 → "압축해제된 확장 프로그램을 로드" → 이 폴더.

테스트: `node --test parse.test.mjs`
